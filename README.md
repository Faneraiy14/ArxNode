# ArxNode

Виконує програми, написані на мові **ArxLang** (`.arx` файли). Аналог
`node.js`, тільки для ArxLang: готовий бінарник, встановлення, менеджер
бібліотек — .NET встановлювати не треба.

Вихідний код самої мови — окремий репозиторій:
[github.com/Faneraiy14/ArxLang](https://github.com/Faneraiy14/ArxLang).

## Встановлення

Скачай архів для своєї платформи зі сторінки
[Releases](../../releases/latest), розпакуй.

**Windows:**

1. Клацни правою на `install-arx.ps1` → **«Запустити за допомогою
   PowerShell»** (або `powershell -ExecutionPolicy Bypass -File install-arx.ps1`).
2. Відкрий **нове** вікно термінала (PATH оновлюється лише в нових).

Якщо Windows покаже «Windows захистила ваш ПК» — файл не підписаний
платним сертифікатом. «Докладніше» → «Виконати все одно».

**Linux/Mac:**

```bash
bash install-arx.sh
source ~/.bashrc   # або ~/.zshrc, або просто відкрий новий термінал
```

GUI (`guiWindow` тощо) і графіка (`createCanvas` тощо) працюють лише на
Windows — там усередині Windows Forms, який поза Windows не існує. Решта
мови (компілятор, VM, майже вся стандартна бібліотека) працює однаково
на всіх трьох платформах.

Перевірка після встановлення (будь-яка платформа):

```bash
arx --version
```

## Команди

| Команда | Що робить |
|---|---|
| `arx файл.arx` | запустити файл |
| `arx` | REPL — виконання рядок за рядком, `exit()` для виходу |
| `arx install owner/repo` | встановити бібліотеку з публічного GitHub-репозиторію |
| `arx install` | встановити все з `arx.json` у поточній папці |
| `arx format файл.arx` | форматувати файл |
| `arx lint файл.arx` | перевірити файл на типові помилки |
| `arx --version` | версія |

## Перша програма

```arx
func main() {
    print("Привіт, ArxLang!")
}
```

```bash
arx hello.arx
```

## Бібліотеки

Пакет — будь-який публічний GitHub-репозиторій із `main.arx` у корені:

```bash
arx install owner/repo
```

Тягне його в `arx_modules/<repo>/` і дописує залежність у `arx.json`
поруч із твоїм файлом. Підключення без `.arx` і без шляху:

```arx
import "repo"

func main() {
    print(якась_функція_з_пакета())
}
```

Без аргументу `arx install` ставить усе, що вже перелічено в `arx.json`
поточної папки.
